What you can do on gittr

Same jobs as Help → What you can do on gittr. Start here if you want the product, not the wiring diagram.

Mirror & backup
Copy repos from a forge or your own server onto Nostr git relays (GRASP).
Issues & PRs on Nostr
Reviews, merge, and push updated repo state so other clients see the same tree.
Nostr Pages
Publish a static site from a repo (root index.html, then Push Manifest). Browse /pages.
Nostr apps
Discover installers on /apps. Owners announce a real Release tag from the Code sidebar.
Releases
Forge download assets and NIP-82 listings. A local listing, an announce, and Push to Nostr are three steps.
Bounties & zaps
Fund issues and pay contributors over Lightning.
Import
One repo or bulk from a forge — GitHub and Codeberg (they run it) or GitLab / Gitea / Forgejo (you can run it) — when the code already lives elsewhere.

Getting started: log in → create or import a repo → payments are optional (NWC / LNURL).

How gittr fits in Nostr git

Protocol is shared. Codebases are not. Think events on relays → git bytes on a server → a website or a CLI, not one app per bullet on awesome-nostr.

Protocol
NIP-34 + GRASP
Signed repo / issue / PR events. Clone URLs can list several git hosts.
Git server · gitnostr
git.gittr.space
Bare repos over SSH/HTTPS. Kind 52 keys. This is the disk gittr talks to.
Web · gittr
gittr.space · YOU ARE HERE
The forge UI: Code, issues, PRs, Pages, apps, import, bounties. Built on gitnostr.
CLI · ngit
nostr:// + gitworkshop
Laptop helper + git-remote-nostr. Same events. Different stack. We don’t ship it.

gittr ≠ ngit

  • gittr ships and runs gitnostr.
  • Day-to-day push/pull on gittr.space is SSH/HTTPS to the bridge, not the ngit binary.
  • They interoperate on the same kinds (30617, 30618, issues, PRs).

Where the bits live

  • Repo identity: npub + name on relays.
  • Git blobs: git.gittr.space.
  • Sites: pages.gittr.space. Blobs: blossom.gittr.space.
  • Laptop git: SSH/HTTPS to the bridge. nostr:// is interop (install ngit’s helper). Agents: gittr-mcp over HTTPS + nsec, not SSH.

Issues and PRs are shared (same signed events). The extras — import, Pages, /apps, Lightning bounties, a git server you can SSH to — live on gittr.

Only gittr among these three

gittr

  • Import from GitHub, GitLab, Codeberg, or your own remote.
  • Static Pages and an /apps directory.
  • Lightning bounties on issues. Optional paywall on git push.
  • Its own git bridge: gitnostr on git.gittr.space.

gitworkshop

  • Hosted web client on the ngit stack.
  • Issues, PRs, repo zaps. Git via public GRASP hosts.
  • Pairs with the ngit CLI.

gitplaza

  • Linux desktop app — not a hosted website.
  • Issues and patches (diffs, revisions) on the same events.
  • Kanban and releases. Git via clone tags + GitWorkshop / ngit.
